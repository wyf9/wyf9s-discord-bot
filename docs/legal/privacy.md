# wyf9sBot 隐私政策

**生效日期：2026-10-31**  
**最后更新：2026-10-31**

## 1. 适用范围

本隐私政策仅适用于由 **wyf9（个人开发者，下称“运营者”）** 通过 Discord 应用提供的官方 **wyf9sBot**（下称“本服务”）。

本政策**不适用于**任何第三方自行部署或运营的 wyf9sBot 实例。该等实例的运营者是独立的个人信息处理者，应自行提供隐私说明并承担相应责任。

## 2. 处理的数据

本服务为提供功能而处理以下数据：

| 数据类型 | 示例 | 用途 |
| --- | --- | --- |
| Discord 标识符 | 用户 ID、用户名、服务器 ID、频道 / 帖子 ID、身份组 ID | 权限判定、名单匹配、频道锁定计划、公告订阅、审计记录、语言偏好 |
| 指令输入与消息内容 | 指令参数、待清理消息、反垃圾判定所需的消息 | 执行指令、批量清理、反垃圾处理与自动回复 |
| 配置与运行数据 | 语言设置、动态权限、计划锁定、语音会话、聊天增强开关 | 保存服务器 / 用户偏好并维持功能运行 |
| 日志与审计记录 | 指令调用、错误信息、管理操作、自动处置结果 | 调试、审计、安全与滥用防护 |

本服务不处理支付信息，也不要求你提供密码。

## 3. 处理目的

上述数据仅用于：

- 提供、维护和改进本服务的功能；
- 执行你或服务器管理员发起的操作；
- 进行权限验证、限速、反垃圾和审计；
- 排查故障、保障服务安全并防止滥用；
- 履行适用法律要求的义务。

## 4. 存储与保留

数据主要存储在运营者用于运行本服务的服务器本地文件中，并通过 Discord 平台传输和展示。

- 运行配置、权限、计划锁定、语言偏好等数据会保留至被删除、覆盖或相关功能停止使用。
- 日志按配置轮转和保留（默认保留约 3 天，具体以运行配置为准）。
- 审计日志、反垃圾通知等会作为 Discord 消息存在于相应频道，其保留时间受 Discord 及频道管理设置影响。
- 消息内容通常仅在处理过程中读取；仅在审计、反垃圾转发、自动回复或你主动要求保存时，才可能产生留存。

运营者会在实现处理目的所需期限内保留数据，并在不再需要时删除或匿名化处理。

## 5. 共享与委托处理

运营者**不会出售**你的个人数据。

在以下情况下，数据可能被共享或由第三方处理：

- **Discord**：本服务通过 Discord API 运行，相关数据受 Discord 隐私政策约束；
- **托管服务商**：运营者用于部署和运行本服务的服务器或云服务提供商，仅在提供基础设施所必需范围内处理数据；
- **第三方功能服务**：如你使用表情或推文转换功能，请求会发送至配置的第三方服务，可能包含完成请求所需的技术信息（如 IP 地址、请求参数），但不用于识别或追踪你的身份；
- **法律要求**：在适用法律要求或为保护运营者、用户或公众的合法权益所必需时，运营者可能披露相关数据。

## 6. 数据安全

运营者采取合理的技术和管理措施保护数据安全，包括限制访问权限、使用受控运行环境和定期检查日志。但任何系统都无法保证绝对安全，运营者不能承诺数据绝不会发生泄露、丢失或未经授权的访问。

## 7. 你的权利

在适用法律允许的范围内，你可以请求访问、更正或删除与本服务相关的个人数据，或反对 / 限制某些处理。

你可以：

- 通过 `/lang` 管理语言偏好；
- 通过 `/perm rm` 删除动态权限规则中的用户或身份组；
- 通过 `/lock unplan` 删除计划锁定；
- 联系服务器管理员从服务器配置中移除你的信息；
- 发送邮件至 **legal@wyf9.top** 提出数据相关请求。

为保护数据安全，运营者可能需要验证你的 Discord 账号或请求与数据的关联性。部分审计或 Discord 消息的删除可能受 Discord 平台机制和频道管理设置限制。

## 8. Cookie 与追踪

本服务不使用 Cookie，不进行广告追踪，也不跨服务器建立用户画像。

## 9. 政策变更

运营者可不时更新本政策。更新后的政策将在本页面发布，并标明最后更新日期。重大变更会以合理方式提示。

## 10. 联系方式

隐私相关咨询或数据请求，请联系：**legal@wyf9.top**。
