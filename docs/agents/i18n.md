# i18n / 多语言

- 运行时：`i18n.py`（`t()`、`lang_of()`、`ls()`、`I18nTranslator`）
- 偏好持久化：`lang_store.py` / `lang_settings.yaml`
- 文案：`lang/zh.yaml`（默认）、`lang/en.yaml`
- 指令：`cogs/lang.py`

## 规则

- 所有用户可见文本必须走 `t()` 或 `self._tr(source, key, **kwargs)`，不要硬编码。
- 斜杠命令 / 参数描述用 `ls("ns.key")` 包装。
- 命令名保持 ASCII，不本地化。
- `lang/zh.yaml` 与 `lang/en.yaml` 必须保持键完全一致。
- 语言优先级：用户 > 服务器 > 默认 `zh`。
- 无用户的服务器级消息用 `lang_store.resolve(0, guild.id)`。

## 新增语言

1. 复制 `lang/zh.yaml` 为 `lang/<code>.yaml`。
2. 在 `i18n.SUPPORTED_LANGS` 加入代码。
3. 按需补充 `i18n._LOCALE_TO_LANG`。
